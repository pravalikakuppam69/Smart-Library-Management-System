# Smart Library Management System

A modern and responsive web-based Library Management System designed to manage books, members, book transactions, due dates, and fines through a simple admin dashboard.

## Features

* Admin Login and Logout
* Dashboard with library statistics
* Add new books
* Edit book details
* Delete books
* Search books
* Filter books by category
* Add library members
* Edit member details
* Delete members
* Issue books
* Return books
* Automatic due-date calculation
* Automatic fine calculation
* Overdue book tracking
* Library analytics
* Most issued books
* Recent activity
* Dark and light mode
* Responsive design
* LocalStorage data persistence

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Install the Live Server extension in VS Code.
4. Open `login.html`.
5. Right-click the file.
6. Select `Open with Live Server`.
7. Login using the demo credentials.
8. The library dashboard will open.

## Main Dashboard

The dashboard displays:

* Total books
* Available books
* Issued books
* Total members
* Books by category
* Fine summary
* Overdue books
* Most issued books
* Recent activity

## Book Management

The administrator can:

* Add books
* Update book information
* Delete books
* Search books
* Filter books by category
* Check whether a book is available or issued

## Member Management

The system allows the administrator to:

* Add members
* Edit member information
* Delete members
* View active issued books for members

## Transaction Management

The system supports:

* Book issuing
* Book returning
* Due-date calculation
* Return-date tracking
* Fine calculation
* Overdue tracking

The current fine rate is ₹5 per overdue day.

## Data Storage

The project uses browser LocalStorage to store:

* Books
* Members
* Transactions
* Theme preference
* Admin login information

No external database is required for the current version.
